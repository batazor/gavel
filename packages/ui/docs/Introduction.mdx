# Gavel UI

Компоненты для публичной витрины и операционной админки аукциона. Основа — React, Tailwind CSS и Storybook; схемы процессов собраны на React Flow.

## Характер

Интерфейс сочетает строгость аукционного каталога и скорость торгового терминала: тёплый фон вместо больничного белого, графит для структуры, медь для главного действия. Цвет всегда дублируется текстом или формой — статус не должен зависеть только от оттенка.

## Правила

- Основное действие на экране одно; медный цвет не используем как декор.
- Денежные значения и таймеры — с табличными цифрами, технические ID — моноширинным шрифтом.
- Админка проектируется от исключений: оператор сначала видит проблему, контекст и безопасное действие.
- Граф — средство понять состояние процесса, а не замена таблицам и журналу событий.

## Навигация

Начните с **Prototype / Admin directions**: варианты A, B и C отличаются информационной архитектурой, а не цветовой темой. Затем откройте отдельные компоненты и их Controls.

Для доменных сценариев откройте **Prototype / Complex components**. Там собраны live bidding, closing policy и payment recovery; их отдельные состояния находятся в разделе **Domain**.

Полная карта интерфейсов находится в **Prototype / Product pages**: создание лота, реестр лотов, управление клиентами, профиль клиента и операционный overview. Изолированные страницы собраны в разделе **Pages / Product map**.

## Масштабирование

В меню **Viewport** доступны три контрольных планшетных размера: 768 × 1024, 834 × 1194 и 1024 × 768. На ширинах до desktop админка использует компактную боковую rail-навигацию; полные подписи появляются с 1280 px.

Сложные доменные блоки перестраиваются по ширине собственного контейнера, поэтому одинаково работают в полноэкранной странице, drawer и составной админской раскладке. Таблицы сохраняют ключевые поля и действия, а вторичные колонки скрывают по мере сужения.
