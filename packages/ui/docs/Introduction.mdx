# Gavel UI

Компоненты операционной админки аукциона и публичной панели торгов. React, Tailwind CSS v4, Storybook; схема процесса — на React Flow.

## Характер: achromatic ledger

Интерфейс — аукционная книга. Хром (навигация, панели, кнопки) не несёт цвета: чернила на тёплой каменной бумаге,
линии в один пиксель, без теней в покое. Цвет живёт только на данных и статусах:

- **Медь** — один оттенок на главном элементе данных экрана: текущая цена лота, серия торгов за минуту, дедлайн recovery.
  Не на кнопках и не в навигации.
- **Статусы** — бледная заливка с тёмным текстом того же оттенка. Один статус на строку.
- **Основное действие** — одно на экране, почти чёрное. Второе — серая обводка.

## Правила

- Заголовок экрана — существительное в одном `h1` 24px; подстрока под ним — находка в данных, не описание интерфейса.
- KPI — это шрифт, а не плитка: серая подпись над цифрой, изменение словами с его окном («+186 vs yesterday 14:32»).
  Цвет изменения говорит «хорошо/плохо», а не «вверх/вниз». Ноль и «нет данных» — серые.
- Цифры — табличные, выровнены вправо; деньги — единственное, что набирается жирным. ID — в Geist Mono.
- Таблицы — линейки и выравнивание: серые заголовки 12px без заливки, без зебры, один статус и одно действие на строку.
- Каждый блок имеет пустое, загрузочное и ошибочное состояние, не теряя рамки (`EmptyState`, `Skeleton`, `ErrorState`).
- Графики: одна серия, 2px, без заливки и маркеров; 3–5 тихих линий сетки; событие, которое важно, подписано.

## Карта

- **Components** — Button, Panel и состояния, KPI, Status badge, Avatar.
- **Visualization** — Line chart, Auction flow.
- **Domain** — Closing board (собственный элемент аукциона: лоты, закрывающиеся в ближайший час), Live bid panel,
  Closing policy builder, Settlement recovery.
- **Patterns / Admin shell** — open-plane shell: подписанный сайдбар на фоне страницы, без верхней полосы; на телефоне
  складывается в 48px бар с меню.
- **Pages / Product map** — Overview, Lots, Customers, Customer profile, Create lot на общих демо-данных из `src/data`.

## Данные

Все цифры страниц приходят из `src/data/ops.ts` и `src/data/customers.ts`: итоги считаются из строк, факт,
показанный дважды, — одна переменная, несколько инвариантов проверяются `console.assert` при загрузке.
Перед запуском файл заменяется проекцией BFF.

## Масштабирование

В меню **Viewport** есть телефон, три планшета и «Operator desk» 1440 × 900 — ширина, на которой верстаются админские экраны.
На ширинах ниже 1024px сайдбар уходит в верхнюю полосу, таблицы сворачивают второстепенные колонки в подстроку.
