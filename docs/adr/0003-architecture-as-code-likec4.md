# 3. Architecture as code with LikeC4

Date: 2026-10-21

## Status

Accepted

## Context

Архитектуру нужно показывать на нескольких уровнях (контекст, контейнеры, bounded contexts, деплой) и держать в актуальном состоянии. Картинки в draw.io расходятся с кодом через неделю.

## Decision

Архитектура описывается в LikeC4 (`docs/architecture/*.c4`). Модель одна, views строятся из неё. Валидация модели входит в CI. Диаграммы не рисуются руками.

## Consequences

- Изменение архитектуры — это PR с правкой `.c4` файлов и соответствующим ADR.
- Deployment-модель отражает Istio и Kubernetes явно, что позволяет показать, какие заботы вынесены в меш (ADR-0002).
- Нужен Node.js в dev-окружении и CI только ради LikeC4. Принимаем.
