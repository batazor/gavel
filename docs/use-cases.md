# Юзкейсы

Статусы: **есть** — в модели и сценариях, **next** — следующая очередь, **later** — после MVP, **out** — вне скоупа.
Каждый юзкейс со статусом «есть» имеет `dynamic view` в `architecture/flows.c4`.

## Catalog

| # | Юзкейс | Статус | Заметки |
|---|---|---|---|
| C1 | Выставить лот: название, фото, стартовая цена, срок | есть | `flow_list_lot` |
| C2 | Редактировать лот до первой ставки | next | После первой ставки описание замораживается |
| C3 | Снять лот с торгов до первой ставки | next | `LotWithdrawn` → Auction отменяет торги |
| C4 | Поиск и фильтрация лотов | later | Read-модель, отдельная проекция |
| C5 | Модерация лота | later | Нужны роли, пока JWT даёт только `user_id` |

## Auction

| # | Юзкейс | Статус | Заметки |
|---|---|---|---|
| A1 | Открыть торги по `LotListed` | есть | `flow_list_lot` |
| A2 | Ставка | есть | `flow_place_bid` |
| A3 | Автоставка (proxy bidding): задать максимум, система перебивает за меня | есть | `flow_proxy_bid`, ADR-0009 |
| A4 | Завершение по таймеру | next | Первая команда не от пользователя. Нужны часы и единственный исполнитель (leader election) |
| A5 | Anti-sniping: ставка в последние N минут продлевает торги | next | Правило агрегата, идёт вместе с A4 |
| A6 | Резервная цена: ниже неё лот не продан | later | Скрытая, как максимум автоставки |
| A7 | «Купить сейчас» | later | Закрывает торги мгновенно, конфликт с текущими ставками — хороший кейс для Lean |
| A8 | Отзыв ставки | out | Не разрешаем. Проще инварианты, честнее торги |
| A9 | История цены по лоту (страница) | есть | Postgres-проекция без максимумов, `flow_sse_reconnect` |
| A10 | Итог торгов: победитель или «не продано» | next | `WinnerDetermined` уже в событиях |
