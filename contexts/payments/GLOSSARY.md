# Payments glossary

| Термин | Каноническое значение |
|---|---|
| Payment instrument | Провайдер-независимый инструмент участника, пригодный для будущей попытки списания. |
| Debit authorization | Зафиксированное согласие участника с версией условий и серверным временем принятия. |
| Payment attempt | Единственная попытка оплаты для пары `auction_id + settlement_round`. |
| Settlement round | Номер кандидата, назначенный Auction и переданный Processes без пересчёта в Payments. |
| Recovery required | Нетерминальное состояние, в котором текущий кандидат должен продолжить ту же попытку. |
| Provider callback | Подписанное внешнее уведомление, преобразованное адаптером в нейтральный исход. |
| Payment succeeded | Терминальный факт успешной оплаты; на один аукцион допустим только один такой факт. |
| Payment expired | Терминальный факт истечения попытки после подтверждённой отмены/отсутствия успеха у провайдера. |

Названия объектов, статусов и API конкретного провайдера не являются терминами домена Payments.
