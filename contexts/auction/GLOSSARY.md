# Auction

Auction — язык английских восходящих торгов по одному лоту. Контекст владеет ставками, ценой, окончанием торгов и выбором победителя.

## Language

**Аукцион**:
Английские восходящие торги по одному лоту с автоматическим повышением ставки до заданного участником максимума.
_Avoid_: Продажа, лот

**Максимум**:
Секретная верхняя граница, до которой участник готов повышать цену в конкретном аукционе.
_Avoid_: Ставка, текущая цена

**Лидер**:
Участник с наибольшим максимумом; при равных максимумах — участник, подавший свой максимум раньше.
_Avoid_: Победитель, автор последней ставки

**Текущая цена**:
Публичная цена открытого аукциона, рассчитанная из двух наибольших максимумов и шага торгов.
_Avoid_: Максимум лидера, settlement amount

**Шаг**:
Минимальное приращение, необходимое лидеру над вторым максимумом при расчёте текущей цены.
_Avoid_: Ставка

**Псевдоним участника**:
Публичное имя участника, стабильное только внутри одного аукциона и не связывающее его с другими аукционами.
_Avoid_: User id, имя пользователя

**Дедлайн**:
Момент `ends_at`, после которого открытый аукцион разрешено закрыть.
_Avoid_: Плановое окончание, hard deadline

**Settlement candidate**:
Лидер закрытого аукциона, которому предложена оплата, но который ещё не является победителем.
_Avoid_: Победитель, плательщик

**Settlement amount**:
Сумма предложения текущему settlement candidate, пересчитанная без максимумов ранее выбывших кандидатов.
_Avoid_: Closing price, текущая цена

**Closing price**:
Зафиксированная при закрытии публичная цена торгов, которая не меняется при последующем settlement.
_Avoid_: Settlement amount

**Победитель**:
Settlement candidate, для которого успешно подтверждена оплата.
_Avoid_: Лидер, settlement candidate
